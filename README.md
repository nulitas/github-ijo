# Github Ijo

> A script to keep your GitHub contribution graph consistently green. Green Goblin? No. Green GitHub? Yes.

<p align="center">
  <img src="https://raw.githubusercontent.com/nulitas/github-ijo/main/github-ijo.png" alt="Github Ijo">
</p>

## ✨ Features
- Automates git commits to generate activity
- Highly customizable scheduling

## 🚀 Usage

1. Edit the `.bat` file to point to your target GitHub repository file.
2. Run the file using your favorite terminal or schedule it using Windows Task Scheduler (or Cron).

## 🛠️ Built With
- Batch Scripting / Shell Scripting
- Git
